# 部署到 Cloudflare Pages

这个文件夹就是可以直接部署的 Cloudflare Pages 项目：

```
public/      网页文件
functions/   服务器函数：/api/claude（转发 Claude）、/api/proxy（转发其他 AI）、/api/ping
wrangler.toml
```

## 方法一：命令行部署（推荐，包含服务器函数）

需要电脑上装有 Node.js 18 以上。

```bash
cd cloudflare
npx wrangler login                 # 浏览器里登录 Cloudflare 账号并授权
npx wrangler pages deploy          # 第一次会问项目名，直接回车用 novel-writer
```

完成后会给出网址，例如 `https://novel-writer.pages.dev`。以后改了文件，再执行一次 `npx wrangler pages deploy` 即可更新。

## 方法二：网页后台上传

Cloudflare 后台 → Workers 和 Pages → 创建 → Pages → 上传资产，把 `public` 文件夹拖进去。

注意：拖拽上传**不会部署 functions 文件夹**，网站只有静态网页，Claude 用不了，其他 AI 可能因为浏览器跨域被拦截。要完整功能请用方法一，或把这个文件夹放进 GitHub 仓库，在后台选「连接到 Git」，构建输出目录填 `public`。

## AI 怎么用

- 打开网站 → ⚙️ 设置 → 选 Claude，填自己的 Anthropic API Key，选模型（默认 Opus 5.5）。Key 只保存在你自己的浏览器里，经你的 Cloudflare 函数转发给 Anthropic。
- 也可以选 Gemini、DeepSeek、MiniMax、智谱 GLM，填各自的 Key。
- MiniMax 买的是 **Token Plan 订阅**：Key 以 `sk-cp-` 开头，设置里「接口类型」保持「自动」或选「Token Plan」，会走 Anthropic 兼容接口 `https://api.minimaxi.com/anthropic`。订阅 Key 不能用在按量付费接口上，混用会报错（之前的 520 就是这个原因之一）。
- 智谱买的是 **GLM Coding Plan 套餐**：设置里「接口类型」选「Coding Plan」（默认就是），会走 Anthropic 兼容接口 `https://open.bigmodel.cn/api/anthropic`，模型选 GLM-5.2。走普通接口会报「余额不足或无可用资源包」。
- 不想每个浏览器都填 Key：在 Cloudflare 后台项目 → 设置 → 变量和机密，添加机密 `ANTHROPIC_API_KEY`。
  **警告：这样所有能打开网址的人都会用你的 Key 花你的钱。** 加之前先用 Cloudflare Zero Trust 的 Access 给网站加登录保护（只允许你的邮箱）。

## 和 claude.ai 版本的区别

- claude.ai 版用你的 Claude 账号额度，不需要 Key；Cloudflare 版需要 API Key。
- 小说保存在各自浏览器里（换浏览器或清除网站数据会丢失）。记得经常在原稿工作台「导出 JSON」备份；在另一个地方用「导入」即可恢复。
- claude.ai 版、本地 skill 版、Cloudflare 版的书架互不相通，用导出/导入搬运。
